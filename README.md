# Projeto-Geração Tech
O projeto é um e-commerce de tênis, camisetas e acessórios feito em React, HTML, CSS e JavaScript. Projeto final de Front-end, aplicando tudo o que aprendemos: componentes, rotas, filtros, busca e páginas de produto.
